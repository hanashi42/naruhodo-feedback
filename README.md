# Naruhodo (なるほど) — Feedback & Bug Reports

This is the public issue tracker for **Naruhodo**, the Japanese reading assistant
Chrome extension — furigana, hover dictionary, and a personal vocab bank on any
Japanese web page.

- 🐛 **Something broke?** → [Open a bug report](../../issues/new?template=bug_report.yml)
- 💡 **Wish it did something?** → [Open a feature request](../../issues/new?template=feature_request.yml)

No account rules, no formality — a screenshot and the page URL where it happened
already make a great report. Write in whatever language you're comfortable with;
every language is welcome here.
